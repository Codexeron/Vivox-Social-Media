## 🎯 Vivox Nedir?

Vivox, **tek bir platformda** beş farklı dünyayı birleştirir:

| Katman | Ne Sunar |
|---|---|
| 🏠 **Sosyal** | Feed, hikâyeler, DM, Circles, Forum |
| 🎨 **Creator** | Abonelik, bağış, reklam, marka işbirliği |
| 🛒 **Mağaza** | Dijital + fiziksel ürün, lisans, escrow |
| 👨‍💻 **Developer** | Playground, repo, webhook, mini app, API |
| 🤖 **AI** | BYOAI — kendi AI'ını bağla, karşılaştır, yönlendir |

**Vivox felsefesi:** *Bağlan → Üret → Geliştir → Kazan.*

## ✨ Öne Çıkan Özellikler

### 🧠 Vivox AI Hub (BYOAI)
- **3 AI slotu** — İstediğin API'yi bağla (OpenAI, OpenRouter, Groq, Qwen, Anthropic, Custom)
- **5 mod:** Tek AI · Compare · AI Council · AI Router · Judge
- Yan yana model karşılaştırma, göreve göre otomatik yönlendirme
- Şifrelenmiş credential storage (backend)

### 💰 Creator Ekonomisi
- Abonelik tier'ları (₺49 / ₺99 / ₺199)
- Bağış & bahşiş (8 hediye seviyesi)
- Vivox Ads — self-servis reklam yöneticisi (CPC/CPM, A/B test)
- FP → ₺ dönüşüm

### 🛒 Mağaza & Ticaret
- Dijital + fiziksel ürün desteği
- 3 tip lisans: Personal · Commercial · Extended
- Kargo entegrasyonu (Aras, Yurtiçi, MNG)
- İade merkezi, bundle, varyant yönetimi

### 👨‍💻 Developer Merkezi
- Code Playground (HTML/CSS/JS/Python)
- Repo / Snippet yayınlama
- Webhooks (`post.created`, `order.paid`, `subscription.renewed`)
- Bounties — kod görevi aç, ödül kazan
- **GitHub entegrasyonu** (OAuth)

### 🛡️ Güvenlik & Uyum
- Trust & Safety moderasyon kuyruğu
- KYC + Yaş doğrulama
- 2FA / Passkey (TOTP + WebAuthn)
- E2EE DM
- Audit Log + Rate Limit
- KVKK / GDPR veri indir/sil

### 🏆 Oyunlaştırma
- FP (harcanabilir) / XP (seviye) ayrımı
- Günlük görevler + Streak
- Liderlik tablosu

🧩 Modüller
📣 Vivox Ads
Self-servis reklam yöneticisi. CPC/CPM hedefleme, A/B test, bütçe kilit, fraud filtre.

⭐ Abonelikler
Creator tier'ları: Başlangıç ₺49 · Pro ₺99 · Studio ₺199. Özel içerik kilidi + üye rozeti.

🎁 Bağış & Bahşiş
Canlı yayında hediye (☕ 10 FP → 🌟 1000 FP). FP → ₺ dönüşüm.

💳 Vivox Pay
QR ödeme, fatura, işlem geçmişi, çoklu para birimi (TRY/USD/EUR).

📅 Etkinlikler
RSVP, takvim entegrasyonu, hatırlatma, canlı yayına bağlama.

📊 Anket & Quiz
Post içi anket + canlı yayın quiz'i. Doğru cevaba FP ödül.

🏆 Oyunlaştırma
Günlük görev zinciri, XP/FP ayrımı, haftalık liderlik tablosu.

🎙️ Sesli Odalar
Twitter Spaces tarzı canlı ses. Konuşmacı/dinleyici rolleri.

💬 Forum
Thread bazlı tartışma, kabul edilen cevap, oy sistemi.

🎯 Bounties
Kod görevi aç, çözene ₺/FP ödül. Otomatik test doğrulama.

📚 Koleksiyonlar
Beğendiğin içerikleri klasörle, herkese açık/paylaşılabilir liste.

🏫 Kampüs
Üniversite, şirket, şehir bazlı özel topluluk alanı.

⚡ Code Playground
Tarayıcı içi kod çalıştırıcı (HTML/CSS/JS/Python). Paylaşılabilir link, sandbox iframe.

📦 Repo / Snippet
Kod yayınla, sürüm notu, fork, star.

🔔 Webhooks
post.created, order.paid, subscription.renewed — developer olay akışı.

🛒 Sipariş Yönetimi
Sipariş listesi, kargo/dijital teslim, iade durumu.

📜 Lisanslama
Personal · Commercial · Extended — ticari kullanım kapsamı.

⬇️ Dijital Teslim
Otomatik link, süre sınırı, DRM, watermark.

🎨 Stok & Varyant
Beden, renk, sürüm varyantları.

📦 Fiziksel Ürün
Kargo takip, stok, ücretsiz kargo limiti.

🏪 Satıcı Paneli
Satış raporu, müşteri mesajları, puanlama.

⭐ İnceleme & Puan
Doğrulanmış alışveriş rozeti, fotoğraflı yorum.

🚚 Kargo Entegrasyonu
Aras, Yurtiçi, MNG — otomatik takip kodu + desi hesaplama.

↩️ İade Merkezi
Talep → onay → kargo → stok girişi → para iadesi.

🎁 Bundle
Birden fazla ürünü indirimli paket olarak sat.

🛡️ Trust & Safety
Moderasyon kuyruğu, severity (low/mid/high), karar geçmişi.

⚖️ İtiraz
Ban itirazı, hakem değerlendirmesi.

🔞 Yaş Doğrulama
18+ içerik kilidi + doğrulama akışı.

🪪 KYC
Kimlik ön/arka + selfie. Satıcı/creator için zorunlu.

🔐 2FA / Passkey
TOTP (Google Auth) + WebAuthn (Touch ID, Windows Hello) + yedek kodlar.

💻 Oturum Yönetimi
Aktif cihazlar, uzaktan çıkış, şüpheli giriş uyarısı.

📁 Veri İndir / Sil
KVKK / GDPR uyumlu hesap verisi paketi + kalıcı silme talebi.

📜 Audit Log
kim, ne zaman, neyi değiştirdi — 7 günlük kayıt.

⏱️ Rate Limit
Kullanıcı başına kota göstergesi (yeşil/turuncu/kırmızı).

🔒 E2EE DM
Uçtan uca şifreli mesajlaşma. Anahtarlar cihazda.

🚫 Engelleme
Engellenen hesaplar + sessize alınanlar.

🪪 Vivox Passport
Doğrulanabilir kimlik kartı + rozetler + Social Identity.

🐙 GitHub Entegrasyonu (Yakında)
OAuth ile GitHub bağla → commit akışı, repo vitrini, katkı grafiği, doğrulama rozeti.
